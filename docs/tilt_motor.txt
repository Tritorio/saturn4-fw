TILT (X) MOTOR DRIVER - REGISTER DUMP (read-only), 2026-10-23, libsgtap with `tiltdump` (sgtilt.c)
====================================================================================================
Command: `echo tiltdump > /tmp/sgweb/cmd.NNNN` on the printer (idle only, not during a job) ->
sglog/tiltregs_<time>.txt, "name reg value". Reads under the app's SPI mutex via the app's own
read op 0x84be4 (it reads twice and retries until two reads agree). NOT read: GSTAT 0x01,
RAMP_STAT 0x35, ENC_STATUS 0x3b (event bits clear on read). Raw dump: backups/tilt/tiltregs_20261023_185700.txt
(printer idle after a power cycle, no hold current: user setting 0).

FINDINGS
- IOIN 0x1100008d: top byte = chip VERSION 0x11 = TMC5130 / TMC2130 family, NOT a TMC5160 (0x30).
  The register map used by the app is common to both (so far "TMC5160-like" in the notes was right
  for the addresses, wrong for the chip: no GLOBAL_SCALER, PWM_AUTO 0x72 not present, reads 0).
- GCONF 0x4 = en_pwm_mode: StealthChop is ON (as the init writes). TPWMTHRS reads 0 (write-only on this
  family, so no information; the init writes none -> StealthChop at every speed).
- CHOPCONF 0x000100c3 = TOFF 3, HSTRT 4, HEND 1, TBL 2 (36 clocks), vsense 0, MRES 0 (256 microsteps),
  intpol 0 (bit 28 NOT set; irrelevant at MRES 0). CORRECTION: the earlier note "256 microsteps + interpolation" was wrong in the
  interpolation part. HSTRT/HEND only matter in SpreadCycle (never entered while TPWMTHRS = 0).
- Write-only registers read 0 and say nothing: IHOLD_IRUN, PWMCONF, TPOWERDOWN, TPWMTHRS, VSTART, A1, V1, AMAX, VMAX,
  DMAX, D1, VSTOP, TZEROWAIT (XTARGET reads back). The ramp values stay known only from the RE of the init (0x84e00).
- XACTUAL = XTARGET = 0xffffb239 = -19911 (the rest position, as in the tilt trace); TSTEP 0xfffff (standstill).
- DRV_STATUS 0x80000000: only stst (standstill); no overtemperature / short / open load flags; CS_ACTUAL 0 (hold current 0).
- PWM_SCALE 0x20 (autoscale amplitude 32 left over from the last move). MSCNT 0x1a8, MSCURACT A 126 / B -213.
